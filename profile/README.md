# SiliconBrane Inc

SiliconBrane Inc is a Canadian IoT research and development company based in Windsor, Ontario, founded in 2018 by Kaushik Ray and Charrie Ray.

## What we build

**Drover** — an off-grid GPS tracker for hiking and camping groups, kids, older parents, and pets. Drover trackers talk to a pocket hub over long-range LoRa radio — *your circle, one map, no cell service required* — and the hub relays positions to the Drover app over BLE. Learn more at [drovertracker.com](https://drovertracker.com).

**KiCad AI Router** — an open-source (GPL-3.0) routing finisher for KiCad 10: an AI orchestrator chooses what to try, deterministic code draws the copper, and an exact verification gate accepts or reverts every result. Developed in the open, with published measured results: [github.com/kaushikray2/kicad-ai-router](https://github.com/kaushikray2/kicad-ai-router)

## Sponsorship

SiliconBrane Inc is the sponsorship recipient for the KiCad AI Router. The router is an independent, non-commercial open-source project — it is not sold in any form. Sponsorships fund development time, benchmark hardware, and validation boards for the project.
